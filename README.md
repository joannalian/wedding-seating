# 好日子排桌

「好日子排桌」是一個可在瀏覽器中使用的婚宴座位安排工具，適合整理賓客群組、安排桌次、確認每桌人數，以及製作會場桌位配置。

名單只會在目前使用的瀏覽器中處理與保存，匯入 Excel 時不會將名單上傳到伺服器。

## 主要功能

- 從 Excel 一次匯入多個賓客群組，之後可用最新版名單同步更新。
- 一列代表一個群組，不需要先把每位成員拆成多列。
- 群組排入桌次後，自動展開成個別成員。
- 可拖曳整個群組或單一成員到其他桌。
- 座位不足時，可選擇只安排部分成員，剩餘成員保留在待分配區。
- 每桌可分別設定舒適人數與絕對上限。
- 可標示嬰兒椅、素食、備註與喜餅數量。
- 提供列表排桌、圓桌座位圖及飯店場地配置三種畫面。
- 可匯出依桌次排序並帶有分類色彩的 Excel。
- 可匯出 PDF、下載備份及讀取備份。

## 基本使用方式

1. 按「下載範例」，取得 `排桌匯入檔範例.xlsx`。
2. 依照範例欄位填寫賓客資料並儲存。
3. 回到網頁，按「匯入 Excel」。
4. 選擇填好的 Excel，確認預覽內容後按「確認匯入」。若網頁已有名單，按鈕會改為「確認同步」。
5. 待分配區會以整個群組顯示，可將群組拖到指定桌次。
6. 群組進桌後會展開成個別成員，可再拖曳單一成員調整座位。
7. 點「桌次設定」可修改桌名、舒適人數與絕對上限。
8. 使用「座位圖」查看每桌座位、分類、嬰兒椅與素食標示。
9. 全部排完後，可到「場地配置」上傳飯店底圖並放置桌子位置。

## Excel 填寫方式

請使用 [排桌匯入檔範例.xlsx](排桌匯入檔範例.xlsx) 填寫。系統會讀取第一個工作表，第一列欄位名稱請勿修改。

| 欄位 | 填寫內容 | 範例 |
| --- | --- | --- |
| 分類 | 用來統計的大分類，可讓不同群組使用相同分類 | 男方親友、女方親友、同事 |
| 誰 | 群組名稱；只有一人時也填在這裡 | 王家親友、公司同事、小美 |
| 人數 | 這個群組共有幾位，請填整數；同步時填 0 代表整組不出席 | 5 |
| 備註 | 群組相關提醒，沒有可留白 | 希望靠近出口 |
| 兒童座椅 | 這個群組需要幾張嬰兒椅，請填數量 | 1 |
| 素食幾份 | 這個群組共有幾位吃素，請填數量 | 2 |
| 中式喜餅數量 | 整個群組需要的中式喜餅總數 | 1 |
| 西式喜餅數量 | 整個群組需要的西式喜餅總數 | 2 |

### 多人群組範例

如果 Excel 填寫：

| 分類 | 誰 | 人數 |
| --- | --- | ---: |
| 女方親友 | 阿姨一家 | 4 |

匯入時待分配區會顯示「阿姨一家，4 位」。排入桌次後會自動展開為：

- 阿姨一家1
- 阿姨一家2
- 阿姨一家3
- 阿姨一家4

如果只有一人，將人數填 `1`，排入桌次後會直接使用「誰」欄位的名稱，不會加上數字。

## 用最新版 Excel 同步名單

已經排好部分桌次後，可以再次匯入最新版 Excel。系統會先顯示新增、更新、移除的差異，確認後才會修改目前資料。

- 「誰」欄位的群組名稱是辨識同一群人的依據，每個群組名稱必須唯一。
- 同名群組會保留原本的桌次，再更新分類、備註、喜餅、嬰兒椅、素食與人數。
- 人數增加時，新增的成員會留在待分配區，不會自動塞進原桌。
- 人數減少時，會從編號最大的成員開始移除；預覽會提醒其中有幾位原本已入桌。
- 人數填 `0`，或最新版 Excel 已沒有該群組時，整個群組會移除。
- 新出現的群組會加入待分配區。
- Excel 內若有重複群組名稱，系統會停止同步並顯示原因。
- 如果先前曾誤把同一份名單追加匯入，重新同步時會保留已排桌的群組，並在預覽中列出要移除的待分配副本。
- 人數減少或整組移除時，預覽會列出受影響的桌次及成員姓名。

同步完成後，畫面右下方會提供 10 秒的「復原」。重要調整前仍建議先按「下載備份」。

### 填寫注意事項

- 每一列代表一個群組，不是代表一位賓客。
- 「誰」與「人數」為必要欄位。第一次匯入時，人數為 0 的群組不會建立；同步時則代表整組不出席並移除。
- 人數、兒童座椅、素食份數及喜餅數量請填數字，不要填「兩位」或「一盒」。
- 兒童座椅與素食份數不可大於群組人數。
- 喜餅數量是整個群組的合計，不會依群組人數自動倍增。
- 若同一分類包含多個家庭，請分成不同資料列，並讓它們使用相同的「分類」。

## 桌次容量

每桌有兩種容量：

- **舒適人數**：正常安排時建議不要超過的人數。
- **絕對上限**：加位後最多可以安排的人數。

拖曳群組時若座位不足，系統會提示目前剩餘座位，並讓你選擇安排部分成員或使用加位。

## 備份與匯出

- **下載備份**：保存目前所有群組、桌次、座位及場地配置，之後可用「讀取備份」繼續編輯。
- **匯出 Excel**：依桌次排序輸出賓客明細與桌次統計。
- **匯出 PDF**：開啟列印視窗後，選擇「另存為 PDF」。

建議完成重要調整後就下載一次備份。清除瀏覽器資料、使用不同瀏覽器或更換裝置時，原本保存在瀏覽器內的排桌資料不會自動跟著移動。
